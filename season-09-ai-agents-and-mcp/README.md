## Introduction

Teach single-agent systems as engineered control loops around an LLM: tool calling mechanics, planning and state, workflow vs autonomy, the Model Context Protocol, and the safety, evaluation and observability needed to run agents in production. Multi-agent and long-horizon systems follow in Season 10.

## Learning Outcomes

One outcome per module, taken from the closing episode of that module. Every episode's own outcome is listed in the [roadmap](roadmap.md).

- **Module 1 — Tool Use Foundations** (closing episode S09E03, Tool Design: Interfaces, Errors, Idempotency, and Permissions): Specify a tool contract that is safe, testable and model-friendly.
- **Module 2 — Agent Loops, State, and Orchestration** (closing episode S09E07, Planning, Reflection, and Self-Correction): Add verification loops that are grounded in external checks and measure their effect.
- **Module 3 — Model Context Protocol (MCP)** (closing episode S09E10, Building and Hardening MCP Servers): Specify a hardened MCP server design with scoped permissions and auditing.
- **Module 4 — Safety, Evaluation, and Production** (closing episode S09E18, Designing a Production Single Agent: End-to-End Blueprint): Produce a defensible design and launch plan for a production agent.
