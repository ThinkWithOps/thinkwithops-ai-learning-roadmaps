## Introduction

Give learners the Python, data-handling and engineering habits that every later season assumes: how Python really runs, how numerical and tabular data is represented in memory, and how to build reproducible, tested, servable code. Linux, Git and Docker appear here only as the minimum developer environment for AI work.

## Learning Outcomes

One outcome per module, taken from the closing episode of that module. Every episode's own outcome is listed in the [roadmap](roadmap.md).

- **Module 1 — Python Foundations for ML Engineers** (closing episode S01E05, Type Hints, Pydantic, and Data Validation): Define validated schemas for config and API payloads and explain what each layer guarantees.
- **Module 2 — Numerical and Data Computing** (closing episode S01E11, Data Formats and Pipelines: CSV, JSON, Parquet, and Arrow): Choose a format for a workload and design a re-runnable data-prep step.
- **Module 3 — Engineering Practice for AI Projects** (closing episode S01E18, From Jupyter to Production: Notebooks, Scripts, Packages, and Project Structure): Refactor a notebook into a tested, configurable package structure.
