## Introduction

Teach classical supervised and unsupervised learning as mechanisms: what each algorithm optimizes, how it fails, and how to evaluate it honestly. Everything here is the base for deep learning, LLMs and MLOps.

## Learning Outcomes

One outcome per module, taken from the closing episode of that module. Every episode's own outcome is listed in the [roadmap](roadmap.md).

- **Module 1 — Framing the Problem and the Data** (closing episode S03E03, Train/Validation/Test Splits and Cross-Validation): Choose a split strategy that mirrors production and explain what each score really measures.
- **Module 2 — Core Supervised Learning Algorithms** (closing episode S03E09, Gradient Boosting: XGBoost and LightGBM): Train and regularize a boosted model and explain why each hyperparameter changes behavior.
- **Module 3 — Evaluating Models** (closing episode S03E13, Regularization and Hyperparameter Tuning): Run a tuning job whose reported score is an honest estimate.
- **Module 4 — Features and Pipelines** (closing episode S03E15, scikit-learn Pipelines and Preventing Leakage): Build a leakage-safe pipeline that can be saved and reused.
- **Module 5 — Unsupervised Learning and the Full Workflow** (closing episode S03E18, An End-to-End ML Workflow and Systematic Error Analysis): Execute and document an end-to-end tabular ML cycle and justify next steps from errors.
