## Introduction

Teach how machine learning systems are built, shipped and kept healthy: reproducibility, data and feature management, pipelines, CI/CD/CT for ML, distributed and streaming data systems, model serving (including edge and on-device), monitoring and drift, governance, managed ML platforms and platform design. Docker, Kubernetes, CI/CD and cloud appear as supporting infrastructure for ML, not as standalone courses.

## Learning Outcomes

One outcome per module, taken from the closing episode of that module. Every episode's own outcome is listed in the [roadmap](roadmap.md).

- **Module 1 — The ML Lifecycle and Reproducibility** (closing episode S11E05, Reproducible ML Environments: Containers, Dependencies, and Hardware): Build a reproducible, GPU-capable image and explain its remaining nondeterminism.
- **Module 2 — Data and Feature Systems** (closing episode S11E10, Feature Stores: Offline/Online Consistency and Point-in-Time Correctness): Decide whether a feature store is warranted and design for point-in-time correctness.
- **Module 3 — Training Pipelines and CI/CD/CT** (closing episode S11E14, Continuous Training: Triggers, Retraining Policies, and Safe Automation): Define a retraining policy with triggers, gates and fallbacks.
- **Module 4 — Model Serving** (closing episode S11E19, Edge and On-Device Inference: Constraints, Compression, and Runtimes): Select a model, compression approach and runtime for an edge target and verify it against latency, memory and energy budgets.
- **Module 5 — Monitoring, Governance, and Platforms** (closing episode S11E27, End-to-End MLOps Reference Architecture): Present and defend an end-to-end MLOps architecture sized to a given organization.
